## Even has options!
```
Binary Clock - Displays the current time in binary format.
Usage: ./binary_clock [OPTION]
Options:
  -i,  --indicators         Show the powers of two next to the binary representation.
  -t   --time-indicators    Show the hrs, min, sec indicators under each.
  -nt, --no-top             Remove the line that starts the program.
  -hr, --horizontal         Display the clock horizontally.
  -h,  --help               Display this help message and exit.
```
